# **App Name**: ResumeForge AI

## Core Features:

- Template Selection: Browse and select from 10,000+ modern, professional resume templates with responsive previews and template categories.
- Live Template Editor: A Canva-like visual editor enabling inline text editing, font/color/border customization, section reordering, and image adjustments.
- AI-Powered Content Tool: Generative AI is provided to offer resume/CV rewrite, paraphrase or summarization options for the currently selected resume section in the ResumeForge app.
- Custom Font Upload: Allows users to upload custom fonts (.ttf, .otf) to apply to the entire resume, a selected section, or selected text.  Note: currently only Google Fonts are supported.
- Resume Fields Population: Support for all resume fields from the Sarkari Result Tools format, including personal information, career objective (with pre-written options and custom input), academic/professional qualifications, extra qualifications, work experience, and declaration.
- Live Preview: Real-time updates and A4 page preview mode ensuring accurate layout adjustments during editing.
- High-Quality PDF Export: Generate high-quality 300 DPI, A4 size PDF files with embedded custom fonts, preserved colors and layout, and no watermarks.

## Style Guidelines:

- Primary color: Deep teal (#008080) for a professional and trustworthy feel.
- Background color: Light teal (#E0F8F8) for a soft and clean backdrop.
- Accent color: Complementary orange-yellow (#D4A274) to highlight key elements and call to actions.
- Headline font: 'Playfair', a modern serif to give an elegant and fashionable high-end feel.
- Body font: 'PT Sans', a humanist sans-serif for good readability.
- Use modern, minimalist icons for section headers and key actions.
- Maintain a clean and organized layout with clear section divisions and ample whitespace.
- Use subtle animations and transitions for a smooth and engaging user experience.
